# 外卖点什么

一个帮助你决定吃什么的中文网页应用。适配电脑和手机，支持五轮排除、自定义食物和不重复推荐。

## 使用

输入名字，依次勾选五轮中不想吃的食物，然后查看随机推荐。用户名和自定义食物保存在当前浏览器，不会跨设备同步。清除浏览器数据可能删除这些设置。

## 本地运行

使用任意静态文件服务器，例如在本目录运行：

```sh
python3 -m http.server 8000
```

访问 https://jason-muxin-han.github.io/What-to-Order/。也可以直接打开 `index.html`，但离线缓存和安装功能需要通过 localhost 或 HTTPS 访问。

## 部署

将仓库推送至 GitHub 后，在仓库 Settings → Pages 中选择从默认分支的根目录部署。通过生成的 HTTPS 地址访问后，可使用支持的浏览器添加到主屏幕。首次在线加载且离线缓存完成后，可离线使用；浏览器对安装的支持有所不同。

## 隐私

应用不需要账号，不上传用户名或自定义食物。页面字体可能由浏览器从 Google Fonts 加载；离线或无法连接时自动使用系统字体。
